ELEANOR

Design System — Webmotors

Contexto

A empresa já havia tentado por três anos desenvolver um design system, sem sucesso. Fui convidada a liderar o projeto, conectando designers e desenvolvedores para construir bibliotecas de componentes para desktop, mobile e aplicativo.

Os maiores desafios foram:

  • Desenvolver o sistema sem um time de tecnologia 100% dedicado.
  • Demonstrar a relevância do Design System para a empresa.
  • Trazer diretrizes claras para garantir a consistência das interfaces.

Desafio visual

Haviam três bibliotecas descentralizadas, com componentes repetidos, que comprometiam a consistência entre os produtos. Eleanor utilizava Poppins e uma paleta que não era otimizada para interfaces digitais.

Como solução:

  • Criei bibliotecas de componentes e tokens para Web e aplicativo.
  • Redefini as cores, preservando a essência da marca.
  • Substituí Poppins por Figtree para melhor leitura digital.
  • Documentei propriedades, estados e casos de uso dos componentes.
Biblioteca de componentes e tokens

Desafio técnico

Sem um time técnico focado no design system, contamos com desenvolvedores front-end de outros produtos. Os testes da nova biblioteca revelaram inconsistências de funcionalidade, código, visual, empacotamento e SEO.

Como solução:

  • Adaptamos a arquitetura para React, Next.js e Vite.
  • Refatoramos componentes fora das especificações.
  • Definimos responsabilidades por produto e code review.
  • Documentamos um passo a passo para colaboração na biblioteca.

Resultados

Hoje, Eleanor está em dois momentos: referência para novas visões de produto e implementação tecnológica para refatorar componentes antigos.

Até o momento:

  • Redução de 17 para 10 dias na esteira de design.
  • Mais de 50% dos componentes adotados no produto B2B.
  • 15% de eficiência nas refatorações dos produtos.

Próximos passos:

  • Dashboard de adoção de componentes e tokens.
  • Bibliotecas para aplicativo.
  • Automação para mudanças de temas e marcas.
Interfaces consistentes, prontas para evoluir

Referências

Uma linguagem compartilhada para orientar decisões de produto.

Eleanor tem servido como referência unificada para alinhar a identidade dos produtos aos objetivos de marca e negócio, permitindo que as equipes construam novas visões a partir de fundamentos sólidos.
